# 費用の試算

2026-11-17 時点の、OpenRouter の公開価格。1ドル = 150円で換算。実際の使用量(特に推論トークン)は、動かして確認する。

- **エンベディング(最初の1回)**: 5,709段落 / 1,756,213字 / 約189万トークン(cl100k_base での実測)。`text-embedding-3-small` は $0.02 per 1M tokens なので **約 $0.04(約6円)**。プレフィックス付き案を試しても +約8.5万トークン。何度やり直してもほぼ無料
- **1回の相談(実行時)**: 約 $0.014〜0.03(約2〜4.5円)
  - 入力約1,800トークン(システム指示+悩み+引用3件)で約 $0.003
  - 出力約1,500トークンで約 $0.011
  - 推論(reasoning)トークンがあれば、約 $0.015 まで上乗せ
  - 出力が大半を占める。クエリの埋め込みは無視できる額
- **1,000回の相談**: 約 $14〜30(約2,000〜4,500円)
- **DB 容量**: ベクトルだけで約35MB(5,709 × 1,536 × 4バイト)。テキストなどを足して100MB前後の見込み
- 長い段落でも最大約3,000トークンで、エンベディングの上限(8,191)には収まる
- テキスト生成: `google/gemini-4-hydrogen`(入力 $1.5 / 出力 $7.5 per 1M tokens。2026-11-17 に OpenRouter での実在を確認)
